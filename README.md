# ballast-app

iOS + Apple Watch app for ballast tank monitoring (BLE). Pico firmware in `pico/`.

**GitHub:** [github.com/joelevy1/ballast-app](https://github.com/joelevy1/ballast-app)

## Dev paths

| Machine | Suggested path |
|---------|----------------|
| Google Drive | `boat stuff/Boat-projects/ballast-app` |
| Windows (short path) | `C:\dev\bleapp` or rename to `C:\dev\ballast-app` |
| Mac | `~/dev/ballast-app` |

After clone/rename, set remote: `git remote set-url origin https://github.com/joelevy1/ballast-app.git`

## Quick start

```bash
npm ci
npx expo start
```

See `DEBUG_SETUP_CHECKLIST.md` for full iOS/Mac/PC workflow.
